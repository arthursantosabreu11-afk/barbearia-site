BARBEARIA ELITE - SITE DE AGENDAMENTO

Arquivos: index.html, style.css e script.js.

TESTE: extraia o ZIP e abra index.html.
PUBLICAÇÃO: envie os três arquivos para uma hospedagem de site estático.

A versão atual salva os agendamentos no navegador (localStorage). Assim, para uso real por vários celulares, é necessário conectar um banco de dados, como Supabase, e criar um painel administrativo.

PERSONALIZAÇÃO: edite o nome, preços e horários no index.html.
